04 · FAQ

Questions people actually ask.

The short answers — with the long ones one tap away.

How do I convert binary to decimal?+

Multiply each binary digit by its corresponding power of 2 and add them up. In this tool, set Convert from to Binary and Convert to to Decimal, then enter your binary value — the result appears instantly.

What is hexadecimal and why is it used?+

Hexadecimal is a base-16 number system using digits 0–9 and letters A–F. It's widely used in computing because it compactly represents binary data — each hex digit maps to exactly four binary bits.

Can I convert fractional binary numbers like 101.101?+

Yes. This tool supports fractional values in all bases. The digits after the radix point are converted using negative powers of the base, and you can adjust the decimal precision from 0 to 8 places.

What's the difference between octal and hexadecimal?+

Octal is base-8 using digits 0–7, while hexadecimal is base-16 using 0–9 and A–F. Both are used as shorthand for binary: one octal digit equals three binary bits, and one hex digit equals four binary bits.

Can I see a number converted into every base at once?+

Yes. Enable Show advanced under Advanced options and the results panel will display a full table converting your entered value into binary, octal, decimal, and hexadecimal simultaneously.

Is this binary converter free and does it work offline?+

It's completely free with no account needed. All conversion logic runs in your browser using JavaScript, so no data is sent anywhere and it works offline once the page is loaded.
