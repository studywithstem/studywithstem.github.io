04 · FAQ

Questions people actually ask.

The short answers — with the long ones one tap away.

What is a file hash and why should I check it?+

A file hash is a fixed-length string generated from a file's contents. Even a tiny change in the file produces a completely different hash. Comparing hashes confirms the file downloaded correctly and hasn't been tampered with.

Which hash algorithms does this tool support?+

It calculates MD5, SHA-1, SHA-256, SHA-512 and CRC32. SHA-256 and SHA-512 are the recommended choices for security; MD5 and SHA-1 are still useful for quick integrity checks and legacy compatibility.

Are my files uploaded to a server?+

No. Every hash is computed locally in your browser using the Web Crypto API and a lightweight CRC32 implementation. Your files never leave your device — nothing is uploaded, logged or stored.

How do I verify a downloaded file?+

Paste the hash published by the download source into the reference field, drop the file into the tool, and check the match indicator. If the computed hash matches the reference, the file is intact.

Why do MD5 and SHA-1 still exist if they're considered weak?+

They're fast and widely supported. Many download pages and legacy systems still publish MD5 or SHA-1 checksums. For security-critical verification, prefer SHA-256 or SHA-512.

Can I hash multiple files at once?+

This tool processes one file at a time. For batches, hash each file individually — the computed hashes can be copied or downloaded as a text file.

Does this tool store or remember any file I hash?+

No. Nothing is saved, logged or synced anywhere. Once you refresh or close the page, all computed hashes and file data are gone for good.

Is this file hash checker free?+

Yes, it's completely free with no account, no sign-up, and no limit on how many files you hash.
