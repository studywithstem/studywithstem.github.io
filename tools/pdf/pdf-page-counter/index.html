04 · FAQ

Questions people actually ask.

The short answers — with the long ones one tap away.

How do I count pages in a PDF with this tool?+

Add one or more PDF files using the drop zone or file browser. The tool reads each file locally and instantly shows the page count for every file plus the combined total — nothing is uploaded.

Are my PDF files uploaded to a server?+

No. The page counting happens entirely inside your browser using JavaScript. Your PDFs never leave your device, which also means it works without an internet connection once the page has loaded.

Can I count pages in multiple PDFs at once?+

Yes. Add as many PDF files as you like, and the tool will show the page count for each file individually along with the total number of pages across all files.

Does the tool work with password-protected PDFs?+

The tool attempts to read encrypted PDFs with the ignoreEncryption option. If a file is password-protected and cannot be opened, it will be skipped and a warning will appear.

Is there a limit on file size or number of PDFs?+

There's no fixed cap enforced by the tool, but since everything runs in your browser's memory, very large files or dozens of PDFs at once will depend on your device's available memory.

Does counting pages affect my PDF files?+

No. The tool only reads the files to count their pages — it never modifies, re-saves, or alters your original PDFs in any way.

Is this PDF page counter free to use?+

Yes, it's completely free with no account, no sign-up, and no watermark. You can use it as many times as you need.
