04 · FAQ

Questions people actually ask.

The short answers — with the long ones one tap away.

How do I test a regular expression with this tool?+

Type or paste your pattern into the regex field, add your test string below, and matches highlight instantly. Flip flags or switch to Replace mode to iterate on your expression.

Is my data uploaded to a server?+

No. All matching runs locally in your browser using JavaScript's RegExp engine. Your pattern and test string never leave your device.

Which regex engine does this use?+

It uses the native JavaScript RegExp engine, so the syntax and behavior match what you get in Node.js, browser JavaScript, and most modern runtimes.

Can I see capture groups and named groups?+

Yes. Every match lists its numbered capture groups and any named groups, along with the character position where the match starts.

What flags can I toggle?+

You can toggle g (global), i (case-insensitive), m (multiline), s (dotAll), u (unicode), and y (sticky). The active flags are shown next to the pattern field.

Does this tool support find and replace?+

Yes. Switch to Replace mode, type a replacement string using $1, $2, or $<name> references, and the transformed output updates live.

Is this regex tester free to use?+

Yes, it's completely free with no account, no sign-up, and no limit on how many times you use it.
