04 · FAQ

Questions people actually ask.

The short answers — with the long ones one tap away.

How do I use this Markdown editor?+

Start typing in the left panel, or drop in a .md file. The right panel shows a live HTML preview as you write. Use the toolbar for quick formatting, then copy or download the result when you're done.

Is my Markdown uploaded to a server?+

No. Parsing and rendering happen locally in your browser using JavaScript. Your text never leaves your device, so it's safe to use with private notes or unpublished drafts.

Which Markdown features are supported?+

The editor supports standard Markdown plus GitHub-flavored extensions: tables, task lists, strikethrough, autolinks, fenced code blocks with syntax highlighting, and footnotes.

Can I export my Markdown as HTML?+

Yes. Tap Download HTML or Copy HTML to grab the rendered output, or Download .MD to keep the raw source. Everything is generated locally.

Does the editor support syntax highlighting in code blocks?+

Yes. Fenced code blocks with a language tag (for example, ```javascript) are highlighted using highlight.js, covering the most common programming and markup languages.

Is there a word count or reading time?+

Yes. The stats bar shows words, characters, lines, and an estimated reading time based on 200 words per minute.

Can I use this editor on my phone or tablet?+

Yes. The layout stacks vertically on smaller screens so the editor and preview stay usable on phones and tablets.

Is this Markdown editor free to use?+

Yes, it's completely free with no account, no sign-up, and no limit on how many times you use it.
