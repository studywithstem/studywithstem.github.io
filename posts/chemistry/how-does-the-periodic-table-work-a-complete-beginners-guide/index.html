How Does the Periodic Table Work?

A complete beginner's guide to the map of every element — what groups, periods and atomic number really mean, and why chemistry stops feeling random once you can read it.

9 MIN READ · INTERACTIVE ELEMENT EXPLORER INSIDE

The periodic table looks like a grid of letters and numbers. It's actually a seating plan where every element sits next to the ones it behaves like — and once you see the pattern, you can't unsee it.

The periodic table is a single chart that organises all 118 known elements in order of increasing atomic number, while arranging them so that elements with similar properties line up in the same vertical column. That one design choice is what makes the table so powerful: it doesn't just list the elements, it predicts how they will behave.

ATOMIC NUMBER

Order, not guesswork

Every element is defined by how many protons its nucleus contains. Hydrogen is 1, helium is 2, and on it goes to 118.

GROUPS

Vertical families

Columns group elements with the same number of outer electrons, so they react in similar ways.

PERIODS

Horizontal trends

Rows show properties shifting step by step from metallic on the left to nonmetallic on the right.

Why the Table Is Ordered the Way It Is

ORDER = ATOMIC NUMBER

Before the modern table, chemists had tried arranging elements by atomic weight, and the pattern kept breaking. The fix came when Henry Moseley showed that each element has a unique positive charge in its nucleus — the number of protons. Ordering by that number, rather than by weight, made every element fall into place.

So the periodic table is sorted left to right, top to bottom, by atomic number: the count of protons in the nucleus. Hydrogen has 1, helium 2, lithium 3, and so on. That number is the element's identity — change it and you have a completely different element.

Z = protons Z (atomic number) is the number of protons in the nucleus. For a neutral atom, it is also the number of electrons orbiting it.

The clever part is the second organising rule: elements are arranged so that those with the same number of outer-shell electrons land in the same column. Since outer electrons drive chemical behaviour, the table becomes a behaviour chart, not just a list.

Groups: The Vertical Columns

SAME OUTER ELECTRONS, SIMILAR BEHAVIOUR

A group is a vertical column. There are 18 groups in the standard table. Elements in the same group have the same number of electrons in their outer shell, which is why they tend to react in the same way.

  • Group 1 — alkali metals: lithium, sodium, potassium. One outer electron, so they are soft, reactive and fizz in water.
  • Group 2 — alkaline earth metals: magnesium, calcium. Two outer electrons; reactive, but less violently than group 1.
  • Group 17 — halogens: fluorine, chlorine, bromine. Seven outer electrons; they are hungry for one more, which makes them reactive nonmetals.
  • Group 18 — noble gases: helium, neon, argon. Full outer shells, so they barely react at all.
The key idea

Chemistry is mostly about outer electrons. Put elements with the same outer count in one column and you can predict how an entire family will behave by knowing one member.

Periods: The Horizontal Rows

LEFT TO RIGHT, METAL TO NONMETAL

A period is a horizontal row. There are seven periods. Moving across a period from left to right, each element has one more proton and one more electron than the one before it. Because the extra electrons go into the same outer shell, the atom's size shrinks slightly and its pull on electrons grows.

The visible result: a period begins with a reactive metal on the far left, slides through less reactive metals, crosses a diagonal band of metalloids, and finishes with reactive nonmetals and a noble gas on the far right.

How to Read a Single Element Cell

SYMBOL, NUMBER, MASS

Every cell on the table carries the same information. Learn to read one and you can read all 118.

11 Na SODIUM 22.99

A typical periodic table cell for sodium.

  • 11 — atomic number: sodium has 11 protons.
  • Na — chemical symbol: short code used in formulas.
  • SODIUM — element name.
  • 22.99 — relative atomic mass: average mass of its atoms compared with carbon-12.

Metals, Nonmetals and the Staircase

WHERE ELEMENTS SIT = WHAT THEY DO

The table splits into three broad regions. Most elements — roughly three-quarters — are metals, clustered on the left and centre. Nonmetals occupy the upper right. Between them runs a diagonal band of metalloids.

  • Metals: shiny, malleable, good conductors of heat and electricity. Think copper, iron, aluminium, gold.
  • Nonmetals: dull or brittle, poor conductors. Think oxygen, sulfur, chlorine, carbon.
  • Metalloids: in-between behaviour. Silicon and germanium sit on the staircase and are the backbone of semiconductors.
Why the staircase matters

The step-like boundary between boron, silicon, arsenic and the rest isn't decoration — it marks the transition from electron-donating metals to electron-hungry nonmetals, which is why the elements along it make such useful semiconductors.

The Trends That Make Chemistry Predictable

PATTERNS YOU CAN COUNT ON

Because the table is built on electron structure, several properties change smoothly across it. You do not need to memorise every element — you need to know these four directions.

  1. Atomic size decreases across a period: more protons pull the same outer shell tighter.
  2. Atomic size increases down a group: each new period adds a whole extra shell.
  3. Reactivity of metals increases down group 1: the outer electron is easier to lose further down.
  4. Reactivity of nonmetals increases up group 17: the pull on incoming electrons is stronger nearer the top.

Why the Periodic Table Still Matters

The table is not a museum piece. It is a working tool used every day in classrooms, labs and industry.

  • Predicting reactions: if you know how one element in a group behaves, you can predict its relatives.
  • Finding materials: semiconductors, catalysts and alloys are chosen by reading the table, not by guessing.
  • Understanding biology: elements like carbon, hydrogen, oxygen and nitrogen sit near the top of the nonmetal region, which is no accident.
  • Discovering new elements: gaps in the table once predicted elements before they were found; that predictive power still guides research today.

FAQ

Questions people actually ask.

The short answers — with the long ones one tap away.

What is the periodic table in simple words?+

The periodic table is a map of every known element, arranged in order of increasing atomic number so that elements with similar behaviour line up in the same vertical column. Reading it left to right and top to bottom follows the number of protons in each atom's nucleus.

What is the difference between a group and a period?+

A group is a vertical column. Elements in the same group have the same number of outer electrons, so they behave similarly. A period is a horizontal row. Moving across a period, atoms gain one proton and one electron at a time, so properties change gradually from metallic to nonmetallic.

Why is hydrogen placed in group 1 if it is not a metal?+

Hydrogen has one outer electron, just like the group 1 metals, so it is placed there for convenience. However, hydrogen is a nonmetal and behaves quite differently from lithium, sodium and the rest, which is why it is often shown floating slightly apart.

What do the numbers in each element cell mean?+

The large number at the top is the atomic number — the number of protons in the nucleus. The letter or pair of letters is the chemical symbol. Below the symbol, you often see the element's name and its relative atomic mass. The atomic number is what defines the element.

Why are some elements called metalloids?+

Metalloids sit along the staircase boundary between metals and nonmetals and share properties of both. Silicon, for example, looks shiny like a metal but is brittle and a poor conductor at room temperature, which is exactly why it became the backbone of computer chips.

How many elements are on the periodic table?+

The standard periodic table currently lists 118 elements, from hydrogen (1) to oganesson (118). Elements beyond uranium are mostly synthetic and exist only briefly in laboratories.
